# Day 03: Data Visualization

This folder introduces data visualization concepts using the Matplotlib library.

## 📁 Directory Structure
*   `notes/matplotlib_intro.py`: Detailed introduction showing how to plot lines, scatter points, bar charts, customize colors, labels, legends, grids, and subplots.
*   `practice/plot_practice.py`: Practice script that takes the student marks dataset and generates custom visual charts.

## 🚀 Getting Started
Run the introduction script:
```bash
python notes/matplotlib_intro.py
```
Run the student performance plotting task:
```bash
python practice/plot_practice.py
```
