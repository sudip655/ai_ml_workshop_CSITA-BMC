# Day 01: Python Basics (A to Z)

This folder contains a complete foundation guide for Python and a series of practice tasks.

## 📁 Directory Structure
*   `notes/python-basics.md`: Extensive guide covering variables, loops, lists, dicts, exceptions, OOP, and file handling.
*   `practice/`: Contains the executable solutions for the 5 Day 1 practice tasks:
    1.  `calculator.py`: Functions for basic math operations.
    2.  `prime_number.py`: Efficient prime number check.
    3.  `vowel_counter.py`: Count frequency of vowels in a string.
    4.  `file_word_counter.py`: Word counter tool reading external files.
    5.  `student_class.py`: Student record management class calculating grades.

## 🚀 Getting Started
Go to the `practice/` directory and run any script:
```bash
python calculator.py
```
