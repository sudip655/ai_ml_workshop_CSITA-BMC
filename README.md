# AI & Machine Learning Workshop

Welcome to the AI & Machine Learning Workshop! This repository contains all notes, exercises, code implementations, and datasets organized day-by-day.

## 📅 Workshop Schedule

*   **Day 01 - Python Basics**: Fundamentals of Python programming, control flows, data structures, file handling, and Object-Oriented Programming.
*   **Day 02 - NumPy & Pandas**: Scientific computing and data manipulation libraries for handling matrices and tables.
*   **Day 03 - Data Visualization**: Plotting datasets, histograms, bar charts, and scatter plots using Matplotlib.
*   **Day 04 - Machine Learning**: Supervised Learning (Linear Regression) and Unsupervised Learning (K-Means Clustering).
*   **Day 05 - Capstone Project**: Summary checklist, real-world case study projects, and advanced learning paths.

## ⚙️ Quick Setup

1. **Virtual Environment Setup (Optional but recommended)**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate   # On Windows
   source .venv/bin/activate  # On macOS/Linux
   ```

2. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```
