# Day 05: Capstone Project & Course Summary

Welcome to the final day of the workshop! Today is focused on building a complete, end-to-end Machine Learning pipeline using all the concepts learned from Day 1 to Day 4.

## 🏆 Capstone Project Guidelines

Choose one of the following datasets to build your capstone project:
1.  **House Price Prediction (Supervised Learning)**: Train a multiple linear regression model to predict housing prices.
2.  **Customer Grouping (Unsupervised Learning)**: Apply K-Means clustering to partition a store's customers into distinct personas.

### 📋 ML Pipeline Checklist
- [ ] **Data Exploration**: Load your data, inspect columns and datatypes, and run descriptive statistics using Pandas.
- [ ] **Data Cleaning**: Handle null values, remove outliers, and prepare columns.
- [ ] **Data Visualization**: Visualize relationships and feature distributions using Matplotlib.
- [ ] **Model Building**: Partition data into train/test sets, fit models, and check validation scores using Scikit-Learn.
- [ ] **Evaluation**: Report final performance metrics (e.g., Mean Absolute Error or Cluster Centroids).
