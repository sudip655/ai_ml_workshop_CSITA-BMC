# Day 02: NumPy & Pandas

This folder contains introduction notes and student analysis tasks using NumPy and Pandas libraries.

## 📁 Directory Structure
*   `notes/day2-1_numpy_pandas_intro.py`: Script introducing basic NumPy array reshaping, operations, and basic Pandas DataFrames.
*   `numpy/`: Folder for NumPy topics (contains `day2-2_numpy_students_marks.py` in the practice directory).
*   `pandas/`: Folder for Pandas topics.
    *   `day2-3_pandas_student_snalysis.py`: Pandas analysis program producing summary statistics, correlation matrices, and performance rankings.
    *   `dummy_data.csv`: A sample dataset.
    *   `dummy_output.csv`: Sample output results.
*   `practice/day2-2_numpy_students_marks.py`: A comprehensive matrix math exercise processing student grades across multiple subjects.

## 🚀 Run Code
To run the Pandas student analysis:
```bash
python pandas/day2-3_pandas_student_snalysis.py
```
To run the NumPy marks checker:
```bash
python practice/day2-2_numpy_students_marks.py
```
